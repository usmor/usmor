## 💻 Projects
### 🎲 CHGKuli

🔗 [Demo](https://chgkuli.up.railway.app/)

A web application for playing "What? Where? When?" (a popular Russian intellectual quiz game).
Built on a dataset of **330,000+ questions** from over **5,500 tournaments**.

**Key features:**
- 🔍 Flexible question search with filters by author, tournament, and year
- 🎮 Game mode with customizable timer, pause, and filters
- 📊 Personal statistics: passed questions, games played, time spent
- 📚 History of games with detailed breakdown and progress tracking
- 🔐 Authorization with a daily personal code for joining games (guests can play without signing up and save results later)

`Python` `FastAPI` `SQLAlchemy` `PostgreSQL` `Alembic` `React` `TypeScript` `Vite` `Mantine` `TanStack Query` `Zustand` `Railway`

Current limitations:

⚠️ No mobile version yet — the interface is optimized for desktop screens. Mobile responsiveness is in the roadmap.

> 💡 A complete pet project showcasing end-to-end development: from asynchronous backend and database design to interactive React UI and cloud deployment.
