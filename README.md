## 🚀 Проектная деятельность

### 🎓 TED Talks Multilingual Search Engine
🔗 [GitHub](https://github.com/usmor/ted_search)

Веб-приложение на **Flask + JS** для поиска по 2000+ TED Talks на трёх языках.
Мультиязычный поиск: автоопределение языка запроса, 3 модели ранжирования
(BM25, Word2Vec, FastText), группировка результатов по переводам.

`Python` `Flask` `Jinja2` `JavaScript` `HTML5` `CSS3` `spaCy` `pymorphy3` `langdetect` `Git`

> 💡 Актуально для EdTech, образовательных платформ и компаний, работающих с поиском и NLP.

### 📖 Справочник по практической стилистике русского языка
🔗 [Демо](https://rus-stylistics.vercel.app/)

Веб-приложение для поиска и систематизации правил русской стилистики.
Трёхступенчатый поиск (по слову, тегу, разделу), адаптивная вёрстка, полная маршрутизация.
Сборка на **Webpack 5** с Babel и линтерами, деплой на **Vercel**.

`JavaScript` `React` `React Router` `HTML5` `CSS3` `Webpack 5` `Babel` `ESLint` `Prettier` `Stylelint` `Vercel`

> 💡 Применимо в EdTech, образовательных платформах и издательствах.
